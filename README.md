# 台灣捷運動態系統

線上版：<https://ctyangthu.github.io/metro-live/>

把台灣五個捷運系統與三條輕軌放在同一張地圖上，依時刻表推算每一班列車現在的位置，並加上高鐵與臺鐵雙鐵，可以跨系統查轉乘。

| 系統 | 路線 | 班次資料 |
| --- | --- | --- |
| 台北捷運 | 淡水信義線、松山新店線、中和新蘆線、板南線（含新北投、小碧潭支線） | 各站時刻表，重建逐班列車 |
| 台北捷運 | 文湖線 | **只有班距**，班次為推估 |
| 新北捷運 | 環狀線、三鶯線 | 各站時刻表，重建逐班列車 |
| 新北捷運 | 淡海輕軌（往崁頂、往淡水漁人碼頭）、安坑輕軌 | 各站時刻表，重建逐班列車 |
| 桃園機場捷運 | 直達車、普通車 | 各站時刻表，重建逐班列車 |
| 臺中捷運 | 綠線（烏日文心北屯線） | **只有班距**，班次為推估 |
| 高雄捷運 | 紅線、橘線 | 各站時刻表，重建逐班列車 |
| 高雄捷運 | 高雄環狀輕軌（順時針、逆時針） | 各站時刻表，重建逐班列車 |
| 台灣高鐵 | 全線 | 官網時刻表（與 rail-live 相同） |
| 臺鐵 | 全車種 | 臺鐵公司開放資料，每日公告時刻（與 rail-live 相同） |

共 14 條捷運與輕軌路線、288 個車站（同名轉乘站合併後 266 個），平日約 5,400 班列車。

## 功能

- **地圖**：雙北、機捷、臺中、高雄、全島等範圍；列車依時刻推算位置，可點選看停站與目前狀態。圖例可逐線開關。
- **即時／模擬**：預設跟著台灣現在時間走，也可以選日期、拖時間軸或加速播放。
- **運行中**：此刻在線上的列車，捷運在前，依路線排列。
- **轉乘查詢**：任選兩站（捷運站、高鐵站、臺鐵站），跨系統找行程，最多轉乘三次。
- **車站看板**：各站兩個方向接下來的班次；同名轉乘站（例如台北車站的板南線與淡水信義線）一起顯示。
- **時刻表**：各捷運路線、高鐵、臺鐵當日班次。

## 捷運資料怎麼來的

來源是交通部 [TDX 運輸資料流通服務](https://tdx.transportdata.tw/)的 `Rail/Metro` 開放資料。

**有各站時刻表的路線**：TDX 只公布「每一站往各終點的發車時刻」，沒有逐班列車，所以 `tools/build_metro.py` 把它重建成列車：從一個發車時刻出發，下一站取最接近預期行車時間的那個時刻，同一路線的列車不會互相超車。終點站沒有發車時刻，到站時間用最後一站的時刻加上站間行車時間。區間車（例如板南線亞東醫院—南港展覽館、淡水信義線北投—大安）與支線都各自重建。

**只有班距的路線**（文湖線、臺中捷運綠線）：TDX 沒有這兩條線的時刻表，只有各時段的班距範圍、首末班車時間與站間行車時間。本系統從首班車開始，以各時段班距範圍的中間值排出班次，一直排到末班車。這些班次是**推估**，不是實際發車時刻，畫面上會標示。

- 班表依星期區分（平日／假日，高雄捷運另分週五、週六、週日），國定假日未另外處理。
- 捷運列車沒有公開的車次編號，畫面上以路線簡稱代替（文湖、淡信、松新、中蘆、板南、環狀、三鶯、直達、普通、綠線、紅線、橘線）。
- 路線以車站間的直線連接，未使用實際軌道線形。
- 淡水信義線廣慈/奉天宮—象山這一站間 TDX 尚無行車時間，暫以 2 分鐘計。
- 淡海、安坑輕軌沒有公布站間行車時間，重建時以站距估計（每公里約 3.2 分鐘）作為比對基準，實際時刻仍取自各站時刻表。
- 高雄環狀輕軌起訖都在籬仔內，一班車繞行一圈約 90 分鐘，分順時針、逆時針兩個方向。
- TDX 的資料偶有錯亂（例如淡海輕軌假日班表在淡金鄧公、新市一路、濱海沙崙三站混入其他路線的時刻）。重建時一班車最多可跨過 2 個比對不上的車站再接回，中間的停站時刻依行車時間內插；仍會留下少數幾班只跑幾站的零碎班次。

## 轉乘

- 同一個路網內，不同路線的同名車站視為站內轉乘（台北捷運與新北捷運算同一個路網，例如板橋、大坪林、頂埔、景安、頭前庄）。
- 輕軌與捷運同名的車站也一樣（紅樹林、十四張、哈瑪星）。另外設定的轉乘點：台北車站（北捷 ↔ 高鐵、臺鐵、機捷）、板橋與南港（北捷 ↔ 高鐵、臺鐵）、松山（松山新店線 ↔ 臺鐵）、新埔 ↔ 新埔民生、三重與新北產業園區（機捷 ↔ 北捷、環狀線）、鶯歌車站（三鶯線 ↔ 臺鐵）、高鐵桃園（機捷）、高鐵臺中／新烏日、大慶、松竹（中捷 ↔ 高鐵、臺鐵）、左營、高雄車站、橋頭、岡山（高捷 ↔ 高鐵、臺鐵）、前鎮之星 ↔ 凱旋、愛河之心 ↔ 凹子底、凱旋公園 ↔ 苓雅運動園區（高雄輕軌 ↔ 高捷）、鼓山、美術館、科工館（高雄輕軌 ↔ 臺鐵）。
- 轉乘的步行與等候時間都是估計值。

## 限制

- 列車位置依表定時刻（或班距）推算，**不含誤點、停駛等即時營運資訊**。TDX 的即時到站資料需要金鑰，靜態網頁無法直接取用。
- 未納入貓空纜車。
- 高鐵、臺鐵的限制與 [rail-live](https://ctyangthu.github.io/rail-live/) 相同。
- 本系統為非官方展示，實際行車以各公司公告為準。

## 專案結構

```
src/app.html              頁面（由 taiwan-live 的地面交通頁改寫而來，資料以佔位字串嵌入）
data/metro.json           五個捷運系統的逐班列車（tools/build_metro.py 產生）
data/                     高鐵、臺鐵資料與台灣地圖（從 rail-live／taiwan-live 複製）
raw/metro/                TDX 原始資料（不納入版本控制）
tools/fetch_metro.py      下載 TDX 捷運資料（已下載的檔案會略過）
tools/build_metro.py      由各站時刻表重建逐班列車；只有班距的路線依班距排班
tools/build.py            組出 dist/index.html
tools/*tra*, *thsr*       與 rail-live 相同的臺鐵、高鐵資料工具
```

## 建置

```bash
python3 tools/build.py
```

更新捷運資料（TDX 未登入時短時間內只能查詢約 20 次，超過會回 429；已下載的檔案會略過，可隔一段時間再執行補齊。有 TDX 帳號可設定 `TDX_TOKEN`）：

```bash
python3 tools/fetch_metro.py
```

```bash
python3 tools/build_metro.py
```

`src/app.html` 是這個專案自己的頁面；rail-live 或 taiwan-live 的頁面有修改時需要手動移植，高鐵與臺鐵資料也要手動複製過來。

## 資料來源

- 捷運：交通部 TDX 運輸資料流通服務（臺北大眾捷運公司、新北大眾捷運公司、桃園大眾捷運公司、臺中捷運公司、高雄捷運公司）。
- 高鐵、臺鐵：[rail-live](https://github.com/ctyangthu/rail-live)（台灣高鐵時刻表、臺鐵公司開放資料）。
- 地圖：[taiwan-atlas](https://github.com/dkaoster/taiwan-atlas)（原始資料為內政部國土測繪中心開放資料）。
